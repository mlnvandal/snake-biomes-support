# Snake Biomes support site

This small, static GitHub Pages site provides the public Support URL and Privacy Policy URL used by the Snake Biomes App Store listing.

## Pages

- `index.html`: support contact path and troubleshooting information.
- `privacy.html`: data practices for the current iOS build.
- `style.css`: shared responsive styling. The site loads no scripts, analytics, or external assets.
- `tiny5-license.txt`: the full copyright notice and SIL Open Font License for the bundled Tiny5 font.

## Publishing

Publish the repository's root on the `main` branch with GitHub Pages. The App Store Support URL is the site root and the Privacy Policy URL is `/privacy.html`.

Before changing the app's data practices, review the policy and App Store privacy answers together. Replace the issue link if the support channel changes.
